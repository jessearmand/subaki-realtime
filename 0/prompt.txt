2. Key Technical Concepts:
   - PersonaPlex: full-duplex speech-to-speech (Moshi architecture), 12.5Hz/80ms Mimi frames, inner-monologue text tokens with PAD gaps (halting cadence is architectural, unfixable in serving), session conditioning via voice prompt (18 presets NATF0-3/NATM0-3/VARF0-4/VARM0-4) + free-text role prompt
   - Prompt template families (from NVIDIA's training data / bundled presets): service ("You work for X which is a Y and your name is Z. … Information: <facts>") and discussion ("You enjoy having a good conversation. [Have a discussion about T.] You are <role> and your name is Z. …") — model anchors reliably only with these; end with what to DO at the open; discussion personas give short greetings from silence, service personas monologue
   - personaplex-mlx WS protocol: binary frames, tag byte 0x00 handshake / 0x01 audio / 0x02 text / 0x06 ping; query params voice_prompt, text_prompt, seed, format; new `format=pcm` mode = raw PCM16 LE @ 24kHz (default `opus` = Ogg Opus via sphn); model steps are INPUT-DRIVEN (client must stream continuously, silence when muted)

   - ScheduledPlaybackQueue vs PlaybackQueue: onended-chained sources incur 1–10ms main-thread gaps at every 80ms frame boundary (crackle); fix = `source.start(when)` at exact AudioContext-clock positions with 160ms jitter lead, re-anchor on underrun
   - AudioWorklet vs deprecated ScriptProcessorNode: ScriptProcessor callbacks run on main thread (React renders jank them); AudioWorklet processes on realtime audio thread, posts chunks zero-copy via MessagePort
   - MLX lazy evaluation: per-session prompt graph deferred until first gen step (PR#4 `sync_state()` fix: 1260ms→75ms handshake-to-first-audio dead time); startup kernel-compile warmup is separate
   - rustymimi StreamTokenizer: no shutdown API; drain result channels before drop to silence "sending on a closed channel" stderr
   - GreetingGate (server-side in fork, client-side for fal): feed model silence until greeting completes (voiced then 600ms quiet, 12s cap); autoGainControl:false always
   - Stack: Next.js 16/React 19/Tailwind v4/bun/oxlint/oxfmt; gates: `bunx tsc --noEmit` → `bun run lint` → `bun run fmt:check` → `bun run build`; python: uv/ruff/ty/pytest
